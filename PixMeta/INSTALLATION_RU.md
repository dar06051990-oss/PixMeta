# Установка PixMeta в Windows

Для обычного пользователя предназначен **PixMeta-Setup-v1.0.0.exe**. Это установщик, не архив исходников. Никаких BAT, Visual Studio и .NET SDK для установки не требуется.

1. Запустите `PixMeta-Setup-v1.0.0.exe`.
2. При желании оставьте галочку ярлыка на Рабочем столе и регистрацию «Открыть с помощью». Ярлык в меню Пуск создаётся всегда.
3. После установки программа запускается из меню Пуск или ярлыком.
4. Чтобы сделать PixMeta просмотрщиком по умолчанию: нажмите правой кнопкой на изображение → **Открыть с помощью → Выбрать другое приложение → PixMeta → Всегда** (названия пунктов зависят от версии Windows). Либо используйте **Параметры → Приложения → Приложения по умолчанию → PixMeta**.
5. Для удаления используйте **Параметры → Установленные приложения → PixMeta → Удалить**.

**Внимание:** исходный ZIP проекта содержит сценарии сборки, но не готовый установщик. Сборка `Setup.exe` происходит через `.github/workflows/build-windows.yml` на Windows runner GitHub Actions или локально через `Build Setup.bat` (разработчику потребуется SDK и Inno Setup).

Программа поддерживает изображения PNG, JPG, WEBP, GIF, BMP, TIFF, AVIF, HEIC и APNG (доступность отдельных кодеков зависит от ImageMagick). Она предназначена для просмотра и чтения AI-метаданных, не изменяет исходные изображения.

**Язык установки:** на русской Windows дополнительные задачи и галочки на завершающем экране отображаются по-русски. Английская версия установщика также сохранена.
