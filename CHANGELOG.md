# PixMeta changelog

## v1.0.0 — First stable Windows installer (2026-11-15)

- Complete Windows x64 setup with the approved PixMeta photo/metadata icon, Start menu and optional Desktop shortcuts.
- Optional **Open with** integration and standard Windows uninstall.
- All installer option descriptions, completion-page choices and Start menu uninstall label localized for Russian and English.
- Self-contained application — no .NET SDK needed to run it.
- Same viewing and AI metadata logic as the previously tested v0.5.19 RC3. The existing AppId is unchanged for updates.

## v0.5.19 RC3

First installer candidate. Built and smoke-tested on GitHub Actions and used successfully by the project owner on Windows.
